DIWALI SURPRISE WEBSITE — NANDINI

All 8 original photos are included in the /photos folder.
To publish on Vercel:
1. Open https://vercel.com/new
2. Import/upload this extracted folder (or drag the folder into Vercel's deploy flow if available).
3. Deploy as a static site. No build command is required; output directory is the project root.
4. Share the resulting public URL.

The site is mobile responsive and uses only local photo files. No face editing or external photo hosting is used.
